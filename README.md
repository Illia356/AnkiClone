# **AnkiClone!**

A lightweight flashcard application inspired by Anki, designed for effective learning languages through spaced repetition.

**Status: Work in Progress (Barely Starting)**  
This project is in its very early stages of development. Core features, architecture, and UI are actively being designed and built from scratch.

**PS: Don't be surprised if you spot some *romaji* in code! This project originally started with the idea of building a dedicated Japanese language learning app, so a few Japanese roots are still hanging around :)**
